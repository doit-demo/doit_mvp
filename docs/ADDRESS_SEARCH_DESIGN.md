# 다국어 주소 검색 — 구현 전 서비스 선택

최신 결정: 사용자가 Google 지도·주소 검색 전환을 선택했습니다. 아래 서비스 비교는 이력이며 구현/키 준비 상태는 GOOGLE_MAPS_SETUP.md가 우선합니다.

## 문제와 목표
현재 주소 입력과 좌표가 연결되지 않아 일본 주소를 입력해도 서울 기본 지도가 남는다. 일본어·영어·한국어 주소를 원문으로 검색하고 위치 후보를 선택하여 업무 목적지 좌표를 저장해야 한다. 언어만으로 국가를 결정하지 않는다.

## 화면 흐름
1. 원문 주소 입력. 선택적 국가 선택(전체/한국/일본 등)으로 동명 주소를 구분한다.
2. 명시적인 주소 검색 버튼으로 CORE 검색 API를 호출한다.
3. 후보의 국가·전체 주소·검색 정밀도(건물/도로/지역)를 표시한다. 첫 후보를 자동으로 확정하지 않는다.
4. 사용자가 선택하면 지도 중심, 목적지 핀, 위도·경도를 함께 갱신한다. 원문 주소는 보존한다.
5. 지도 클릭으로 실제 입구 위치를 보정할 수 있다. 입력한 주소를 바꾸면 이전 좌표·선택 결과를 무효화한다.
6. 결과 없음/연결 오류에서는 좌표를 임의 생성하지 않는다. 국가 추가·주소 수정·수동 지도 선택을 안내한다.

## CORE와 지도
인증된 CORE의 POST /api/geo/search에 주소만 전달한다. 업무 설명이나 첨부파일은 지오코딩 업체로 보내지 않는다. 키는 Worker Secret으로 관리한다. 입력 길이 제한, 요청 제한, 외부 요청 timeout, 안전한 오류 메시지가 필요하다. API provider를 교체할 수 있도록 후보 목록 형식을 통일한다.

검색과 배경 지도는 별도 기능이다. 국내 VWorld는 유지하고 해외는 해당 지역 상세 지도를 표시할 수 있는 공급자로 전환해야 한다. 해외 타일이 HTTP 200이어도 내용이 비어 있을 수 있으므로 HTTP 성공만으로 검증하지 않는다.

## 서비스 선택 대기
기존 지도 구조와 함께 사용하는 후보로 Geoapify의 세계 주소 검색을 제안했다. 실제 검색 검증에는 사용자 API 키가 필요하다. 대안은 Google 지도와 주소 검색의 함께 도입이다. 아직 공급자 설정·계정·유료 사용을 생성하지 않았다.

공식 참고: https://apidocs.geoapify.com/docs/geocoding/forward-geocoding/

## 수용 테스트
- 사용자 예시 일본 주소: 神戸市須磨区弥栄台2丁目5番2. 원문과 영문 표기로 검색 품질 비교. 건물 단위 결과가 아닌 경우 이를 명시한다.
- 한국어 한국 주소, 영어 해외 주소의 후보 국가와 실제 지도 위치 확인.
- 유사 주소 여러 후보, 결과 없음, API 제한, 외부 연결 실패 처리.
- 후보 선택 후 좌표/지도 동시 반영, 주소 변경 후 이전 좌표 제거.
- 다른 검색이 먼저 끝나더라도 오래된 응답이 최신 입력을 덮어쓰지 않음.
- 키가 정적 번들이나 검색 오류에 나타나지 않음.

현재 이 문서는 설계이며 기능 구현·실제 주소 정확도 검증 완료를 의미하지 않는다.
