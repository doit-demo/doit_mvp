# MapTiler 반영

2026-10-07 사용자가 MapTiler 시험 지도를 DOIT에 반영하도록 지시했습니다. 지도와 주소 검색 provider를 MapTiler 우선으로 연결했습니다. 키는 로컬 .env 및 Cloudflare Secret MAPTILER_API_KEY에 저장하며 정적 소스에는 포함하지 않습니다. 브라우저 요청에는 키가 포함됩니다.

주소 입력 → 검색 → 후보 선택 → 지도/좌표 반영. 주소 변경 시 이전 좌표를 초기화합니다. 지역 수준 후보 및 주소 후보를 구분하며 MapTiler 주소 후보를 건물 위치 확정으로 표시하지 않습니다. 앞서 입력한 일본 상세 주소는 정확한 건물 검색이 확인되지 않았으므로 지도에서 실제 위치를 확인해야 합니다.

사용자 비용 절감 지시에 따라 타입 검사와 빌드만 수행하고 반복 디버깅/전체 회귀/추가 브라우저 검증은 하지 않았습니다. 이전 GOOGLE_MAPS_SETUP.md의 Google 전환은 이 변경으로 대체됩니다.
