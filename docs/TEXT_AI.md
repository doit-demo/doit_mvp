# 텍스트 번역·내용 정리

사용자 선택에 따라 Gemini Developer API가 아니라 Google Cloud Vertex AI를 사용합니다. 2026-10-07 GCP_PROJECT_ID와 GCP_SERVICE_ACCOUNT_JSON을 Cloudflare Secret에 등록했습니다. 실제 AI 호출은 실행하지 않았으며 아직 미검증입니다.

클라이언트와 에이전트 화면 상단에서 한국어/영어/일본어를 선택합니다. 선택값은 브라우저의 APP별 localStorage에 보존하며 변경 시 페이지를 새로고침합니다. 기본값은 Client 한국어, Agent 일본어입니다. 고정 UI 문구는 로컬 사전으로 표시하며 AI를 호출하지 않습니다. 이름, 파일명, 지도 사업자의 지도 표기는 원본을 유지합니다.

의뢰 상세는 선택한 화면 언어로 자동 번역하며, 제출된 보고 메모는 Client 화면 언어로 자동 번역합니다. 원문 전환이 가능합니다. 작성 중인 텍스트 번역/정리는 수동 버튼으로 실행합니다. 자동 재시도는 하지 않습니다. 성공 결과는 사용자·원문·언어·작업·문맥·프롬프트 버전 기준으로 재사용합니다. 이전 v1 결과는 보존하지만 재사용하지 않습니다. 사진·영상·GPS는 모델에 보내지 않습니다. API 오류 중 사전에 없는 메시지는 원문으로 표시됩니다.

입력 최대 4,000자, 출력 최대 2,500토큰 및 4,000자. UTC 날짜 기준 사용자 20회/전체 100회, 실패 요청 포함. 입력 원문·결과·행위자·처리 상태는 ai_text_runs에 보존합니다. 상태 전이/완료/검증에 AI 권한을 부여하지 않습니다.

## 연결 설정
- Vertex AI API 활성화 및 크레딧이 연결된 GCP_PROJECT_ID.
- GCP_LOCATION (기본 global), GEMINI_MODEL (기본 gemini-2.5-flash-lite).
- Vertex AI 호출 권한(roles/aiplatform.user)을 가진 서비스 계정.
- 외부 Worker 인증용 서비스 계정 JSON은 Cloudflare Secret GCP_SERVICE_ACCOUNT_JSON에 저장. 소스/브라우저/로그에 노출하지 않습니다. JSON 파일을 사용하는 방식은 조직 정책에서 허용되는 경우에만 사용하며, 금지된 경우 정책을 임의 변경하지 않고 대체 인증 설계를 진행합니다.
- 서비스 계정 파일은 로컬 private/ 아래에 두고 채팅에 개인키를 붙여넣지 않습니다.

이번에는 타입 검사·빌드·migration 및 배포만 진행했습니다. 실제 모델 응답, 번역 품질, 크레딧 차감은 인증 설정 후 별도 확인이 필요합니다. 계정의 크레딧 잔액은 앱이 조회하지 않으므로 위 횟수 제한이 과금액 상한을 보장하지는 않습니다.
