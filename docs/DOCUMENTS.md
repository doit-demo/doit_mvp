# 의뢰서·보고서 시스템

2026-10-08 구현.

- 의뢰 등록과 동일한 D1 batch에서 REQUEST 문서를 발행한다. 문서 번호, 업무 ID, 원문, 의뢰인, 위치, 요청사항, 증거 요구사항, 발행 시각을 보존한다.
- 에이전트는 수행 중 결과(필수, 최대 4,000자)와 특이사항/미완료 사항(선택, 최대 4,000자)을 작성하고 보고서를 제출한다. 작성 중 서버 임시 저장은 이번 범위에 포함하지 않는다.
- 제출 시 업무 상태 변경, Audit, REPORT 문서 저장을 하나의 D1 batch로 처리한다. 현재 회차의 유효 증거 메타데이터, 메모, GPS, 해시를 문서에 보존한다. 파일 자체는 기존 비공개 R2 원본을 사용한다.
- 문서는 DB trigger로 수정/삭제를 금지한다. 재수행 후 제출하면 새로운 회차의 보고서가 추가된다. 관리자 검토와 의뢰인 완료는 기존 문서 내용을 바꾸지 않는다.
- 문서는 기존 업무 상세 API의 documents 필드로 제공하며 visibleTask 소유권 검사를 공유한다. 내부 R2 저장 경로는 문서에 넣지 않는다.
- 세 역할의 업무 상세에서 의뢰서·보고서 목록과 문서 원문을 조회한다. 별도 인쇄 화면에서 브라우저 인쇄/PDF 저장을 지원한다. 이미지 원본은 로그인 상태에서 불러오며 영상은 문서에 메타데이터로 표시한다. PDF에 영상이 내장되지는 않는다.
- UI 제목은 한/영/일로 표시하고 문서 본문은 발행 원문을 유지한다. 기존 AI 번역이 보존 문서를 변경하지 않는다.
- migration 0007: task_documents 및 불변 trigger. 기존 의뢰는 현재 DB에서 재구성하여 MIGRATED로 명시한다. 과거 제출 보고서를 추정하여 발행하지 않는다. 이전 보고 결과는 기존 현장 기록에서 계속 조회한다.

검증: npm run check, npm run build 통과. 사용자 비용 절감 지시에 따라 회귀 테스트·브라우저 인쇄·실기기 검증은 실행하지 않았다. 기존 테스트 중 빈 본문 submit은 필수 summary에 맞춰 후속 갱신이 필요하다.

배포 순서: migration 0007 적용 → 빌드된 Worker 배포. 이전 Worker로 롤백하면 신규 문서 발행이 중단되므로 문서 보존 기능의 롤백은 운영 판단이 필요하다.

## 배포 상태
2026-10-08 원격 migration 적용 시 Cloudflare 오류 7403(계정이 유효하지 않거나 서비스 접근 권한 없음)로 실패했다. 신규 Worker 배포는 진행하지 않았다. 올바른 계정/D1 권한으로 인증한 후 migration과 Worker 배포를 순서대로 재개해야 한다. 현재 운영 사이트에 이 기능이 반영되었다고 볼 수 없다.

## 인증 확인 및 배포 재개
2026-10-08 사용자 요청으로 인증 확인: 기존 OAuth 계정과 D1 쓰기 권한이 정상 확인되었고, 권한 설정 변경 없이 원격 migration 0007 적용에 성공했다. Worker 배포 완료: b4e952d0-cb77-4948-a6cc-582a3485d114. 앞선 7403 오류의 정확한 원인은 확정하지 않았다. 문서 발행/인쇄 전체 흐름 테스트는 실행하지 않았다.

## 수신 역할별 문서 자동 번역
2026-10-08: 문서 열람 시 에이전트는 일본어, 의뢰인은 한국어로 자동 번역한다(화면 언어 설정과 독립). 관리자는 원문을 본다. 제목·의뢰 내용·요청사항·증거 요구·위치·주소·수행 결과·특이사항·증거 메모가 대상이다. 이름, 파일명, 숫자, 좌표, 문서 번호, 해시는 번역 대상으로 보내지 않는다.
원문 DB는 변경하지 않고 기존 AI 성공 결과 캐시를 활용한다. 짧은 필드는 JSON으로 묶으며 긴 필드는 개별 요청한다. 기존 사용자 일일 20회/전체 100회 제한이 적용된다. 부분 실패는 번역 문서 전체를 적용하지 않고 원문과 오류를 표시하며 수동 재시도를 제공한다. 번역 중 인쇄는 비활성화하며 번역본 인쇄에는 AI 번역본 표시가 포함된다. 원문/번역본 전환 가능.
타입 검사와 빌드 통과, 배포 5a5ec940-5fd1-410b-8e36-13001ad2278f. 실제 유료 모델 호출·번역 품질 검사는 실행하지 않았다. 번역은 전달 시 일괄 생성하는 방식이 아닌 수신자가 문서를 열 때 수행한다.
