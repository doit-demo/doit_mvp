# 서로 다른 디바이스에서 검증

실제 휴대폰 검증은 아직 수행하지 않았습니다. 자동 브라우저 테스트의 GPS는 모의 좌표이며 실제 현장 기록이 아닙니다.

1. PC에서 `/admin`, 의뢰인 기기에서 `/client`, 에이전트 휴대폰에서 `/agent`에 각 계정으로 로그인합니다.
2. 의뢰인이 업무 내용·주소·지도 좌표·필요 증거를 입력하고 의뢰합니다.
3. 관리자가 Agent를 배정합니다. Agent 목록에 업무가 표시되는지 확인합니다. 자동 갱신 주기는 15초입니다.
4. Agent가 수락 → 업무 시작을 누릅니다.
5. 위치 권한을 허용하고 현재 GPS를 기록합니다. 좌표·정확도·기록 시각을 확인합니다. 위치 재수집 실패 시 이전 좌표가 사라지는지 확인합니다.
6. 카메라 사진과 짧은 영상을 등록하고 메모를 남깁니다. 파일별 최대 25MB입니다. JPG/PNG/WEBP/MP4/WEBM을 지원하며 HEIC/MOV는 현재 지원하지 않습니다.
7. Agent가 보고를 제출합니다. 관리자와 의뢰인 기기에서 원본 사진·영상과 위치·시간·메모가 표시되는지 확인합니다.
8. 관리자가 사유와 함께 재수행을 요청합니다. Agent가 새 증거를 등록하고 다시 제출합니다.
9. 관리자가 검증 승인 → 완료 처리합니다. 의뢰인 보고서에서 완료 상태와 전체 이력을 확인합니다.
10. 다른 의뢰인/Agent 계정에서는 해당 업무와 원본 URL 접근이 차단되는지 확인합니다.

기록할 항목: 기기/OS/브라우저, 네트워크, 촬영 형식·크기, GPS 권한 허용/거절 결과, 업로드·재생 결과, 오류 메시지. iPhone의 실제 촬영 형식과 영상 코덱 호환성을 특히 확인해야 합니다.
